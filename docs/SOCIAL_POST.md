# Counterstep social copy

## LinkedIn

I built Counterstep for the Google All Things Agentic Hackathon.

An AI agent can finish its task and still leave an operator with risky cleanup. Counterstep starts from an evidence-linked receipt, inspects what is true now, lets Gemini choose a bounded recovery through Google ADK, and passes every proposed write through deterministic citation, authority, transition, version, budget, and idempotency checks.

The best test is a stale-state race. Counterstep plans from version 3, a disclosed external actor advances the resource, and the write is refused. It re-inspects both governed resources, admits one replacement plan, and finishes without overwriting the newer state.

The recorded live deployment uses Gemini 3.5 Flash Lite on Vertex AI, Google ADK for TypeScript, Cloud Run, and Firestore. The public URL now runs the same deterministic recovery contracts as a quota-isolated synthetic fixture. The exact release passed 445 tests, five deterministic evaluations, eight production-repository emulator cases, and six retained managed-Firestore cases.
