## Retained Agent Receipt foundation

Agent Receipt predates Counterstep and supplies the exact-byte trace, canonical
event-accounting, deterministic finding, original receipt, and synthetic CRM
foundation described in [ORIGIN_AND_REUSE.md](../ORIGIN_AND_REUSE.md). Its PRD,
project guide, IBM challenge material, adapters, portable verifiers, evidence
packet, and recovery-plan documents remain in this repository to preserve
history and attribution. They are not the current Counterstep submission
contract or judged runtime path.
